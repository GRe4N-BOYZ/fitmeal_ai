# 要件定義

## 目的

筋トレ・ダイエットをする人が
- 食事
- 体重
- 運動
- 睡眠
を一つのアプリで管理できる。
さらにAIが分析して改善提案を行う。

## 対象ユーザー
- 筋トレ初心者
- ダイエット中
- ボディメイク
- 増量・減量をしている人

## MVP（最初の完成版）

### 認証
- メールログイン
- Googleログイン
- ログアウト

### ホーム
表示内容
- 今日の日付
- 体重
- 体脂肪率
- 朝昼晩の進捗
- PFC進捗

### 食事
登録できる内容
- 朝
- 昼
- 夜
- 間食

入力
- 食品名
- 数量

表示
- カロリー
- P
- F
- C

### PFC
今日
- P 120 /150g

- F 45 /60g

- C 220 /250g

### 体重

- 毎日

- 体重
- 体脂肪率

入力。

### グラフ

表示

- 1週間
- 1か月
- 3か月

### AI

納豆

ギリシャヨーグルト

がおすすめです。

### 非機能要件

#### パフォーマンス
- ホーム画面は3秒以内に表示
- 食事登録はすぐ反映される
#### セキュリティ
- Firebase Authenticationで認証
- Firestore Security Rulesで自分のデータだけアクセス可能
#### バックアップ
- データはFirestoreに保存
- 機種変更後も復元可能
#### 対応環境
- Android（最優先）
- 将来的にiOS対応
