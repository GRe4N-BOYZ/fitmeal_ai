## 🎯 制作背景

筋トレやダイエットでは、トレーニングや食事を継続して記録することが重要です。

一方で、毎日の食事やトレーニングを記録し続けること自体が負担になり、継続するモチベーションを維持することが難しいと感じました。

そこで、単なる記録アプリではなく、

> **「記録すること自体を楽しめるアプリ」**

を目指して開発しています。

将来的には、食事やトレーニングの記録をキャラクターの成長につなげ、**育成ゲームのように楽しみながら健康管理を継続できる体験**を実現することを目標としています。

---

## 🎮 コンセプト

### 「健康管理を、育成ゲームにする」

食事・トレーニング・身体データなどの日々の行動を記録し、その結果をゲーム内のキャラクターの成長へ反映させることを目指しています。

### 想定している基本サイクル

```text
食事・トレーニングを記録
        ↓
栄養・運動状況を確認
        ↓
キャラクターが成長
        ↓
成長や変化を楽しむ
        ↓
次の日も記録する
```

「健康のために記録する」だけではなく、
**「キャラクターを育てるために記録する」**という動機を作ることで、継続的な利用につなげることを目指しています。

## 🏗️ 開発方針

機能を追加していく中でもコードが複雑にならないよう、画面・データモデル・データ保存処理などを役割ごとに分離して開発しています。

また、まずは筋トレメニュー管理などの**基本的な記録機能を実装し、その後に食事管理・AI・育成ゲーム要素を段階的に追加する**方針で開発しています。
