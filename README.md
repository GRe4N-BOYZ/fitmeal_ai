# Fitmeal AI

筋トレ・ダイエット向けAI食事管理アプリ

## 概要

「Fitmeal AI」は、筋トレやダイエットを行う人向けの食事管理アプリです。

### 主な機能

- 🍽 食事記録
- 📊 PFCバランス表示
- ⚖️ 体重・体脂肪率管理
- 😴 睡眠データ連携
- 🏃 運動データ連携
- 🤖 AIによる栄養アドバイス
- 追加予定
- お得な食材情報（スーパーの価格比較等）


## 技術スタック

- Flutter
- Dart
- Firebase
- Riverpod
- Health Connect
- OpenAI API
